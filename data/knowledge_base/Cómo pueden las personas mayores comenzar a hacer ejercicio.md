```
Las personas mayores deben realizar al menos 150 minutos semanales de ejercicio
aeróbico de intensidad moderada, como caminar a paso ligero o bailar rápido. Lo
ideal es estar activo por lo menos tres días a la semana. También deben realizar
actividades para fortalecer los músculos, como levantar pesas o hacer
abdominales, al menos dos días a la semana. Las pautas recomiendan combinar una
variedad de ejercicios, incluyendo actividades de equilibrio, aeróbicas y de
fortalecimiento muscular. Si se prefiere actividad aeróbica de intensidad
vigorosa, como correr, se recomiendan al menos 75 minutos semanales.
```

```
El ejercicio y la actividad física benefician la salud mental y física. Ayudan a
mantener la independencia al envejecer.
```

```
Para comenzar una rutina de ejercicio, se debe iniciar lentamente a partir del
nivel de condición física actual. El exceso de ejercicio puede causar lesiones y
llevar al abandono de la actividad. La clave es progresar a ritmo constante.
Para reducir el riesgo de lesión, se recomienda comenzar con ejercicios de baja
intensidad. Se debe realizar calentamiento antes de la rutina regular y
enfriamiento después. Al hacer ejercicio al aire libre, se debe tener cuidado
con el entorno. Es importante tomar agua antes, durante y después del
entrenamiento, incluso sin sed. Se debe usar ropa y calzado deportivo adecuados
para la actividad. Si se tiene algún problema de salud, se debe consultar con el
médico sobre el plan de ejercicio.
```

```
Es necesario evaluar el nivel de condición física actual para los cuatro tipos
de ejercicio: resistencia, equilibrio, flexibilidad y fortalecimiento. Si se
está en forma para correr pero no se estira, no se obtiene el máximo beneficio.
Se deben anotar los resultados para hacer seguimiento del progreso. Se debe
tomar nota de cómo se siente al hacer ejercicios de prueba. Si fueron difíciles,
se debe hacer lo cómodo y aumentar gradualmente. Si fueron fáciles, el nivel de
condición física es mayor y se puede ser más ambicioso.
```

```
Antes de agregar ejercicio o aumentar el nivel de actividad, se debe hablar con
el médico. Se puede preguntar si hay algún ejercicio o actividad que se deba
evitar, considerando la historia clínica, cirugías recientes o problemas de
salud como artritis, diabetes o enfermedades del corazón. También se debe
consultar sobre cualquier síntoma inexplicable como dolor o presión en el pecho,
dolor en articulaciones, mareos o dificultad para respirar. El médico puede
recomendar posponer el ejercicio hasta diagnosticar y tratar problemas. Se debe
preguntar si el cuidado preventivo está actualizado y si se necesitan pruebas,
como la revisión de osteoporosis para mujeres mayores de 65 años. También se
debe preguntar cómo afecta el problema de salud a la capacidad para hacer
ejercicio. Personas con artritis deben evitar ciertas actividades cuando las
articulaciones están inflamadas. Personas con diabetes pueden necesitar ajustar
horarios, comidas o medicamentos al planificar actividades.
```

```
Para mantenerse motivado, se deben establecer metas específicas, realistas e
importantes. Se deben revisar regularmente a medida que se avanza o cambian las
prioridades.
```

```
Las metas a corto plazo ayudan a integrar la actividad física en la vida diaria.
Se debe pensar en lo necesario para estar físicamente activo, como comprar
zapatos para caminar o completar un registro de actividades. Ejemplos de metas a
corto plazo son: decidir ser más activo hoy, averiguar sobre clases de ejercicio
mañana, preguntar a un amigo si quiere hacer ejercicio juntos al final de la
semana, o asegurarse de tener el calzado y la ropa cómoda en las próximas dos
semanas.
```

```
Las metas a largo plazo se enfocan en dónde se quiere estar en seis meses, un
año o dos años. Deben ser realistas, personales e importantes. Ejemplos son:
nadar 1.5 km tres veces por semana dentro de un año, poder jugar con los nietos
el próximo verano, o tener la presión arterial bajo control en seis meses
mediante el aumento de actividad física y los consejos del médico.
```

```
Para algunas personas, escribir un plan de ejercicio ayuda a cumplir la promesa
de hacer más actividad. El plan debe ser realista. Se puede hacer un contrato
con un amigo o familiar para mantener el compromiso. Se debe revisar y
actualizar el plan y los objetivos regularmente para aprovechar el éxito. Se
debe ajustar el plan si se avanza o si el horario cambia. Situaciones como
vacaciones o enfermedad pueden interrumpir la rutina, pero no se debe desanimar
y se puede comenzar de nuevo.
```
