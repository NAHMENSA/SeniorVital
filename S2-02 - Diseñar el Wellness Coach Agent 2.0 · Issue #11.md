## Objetivo

Diseñar la arquitectura del Wellness Coach Agent 2.0 definiendo propósito, responsabilidades, herramientas, prompt especializado y flujo de razonamiento.

## Actividades

- Definir el rol y alcance del agente.
- Especificar sus responsabilidades.
- Identificar entradas, salidas y fuentes de información.
- Definir las herramientas que podrá utilizar.
- Diseñar el prompt especializado.
- Modelar el flujo de razonamiento y toma de decisiones.
- Elaborar un diagrama de arquitectura o flujo mediante Mermaid.

## Entregables

- Diseño arquitectónico del agente.
- Definición de responsabilidades.
- Prompt especializado.
- Relación de herramientas asociadas.
- Diagrama del flujo de razonamiento.

## Criterios de aceptación

- El propósito del agente está claramente definido.
- Sus responsabilidades están delimitadas.
- Las herramientas utilizadas están justificadas.
- El prompt refleja correctamente el dominio Wellness.
- El flujo de razonamiento está documentado.
- El diseño es coherente con la arquitectura existente.
