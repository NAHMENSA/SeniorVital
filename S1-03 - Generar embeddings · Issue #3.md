## Objetivo

Implementar el proceso de generación de embeddings para transformar los chunks de la base de conocimiento en representaciones vectoriales que puedan ser utilizadas posteriormente para búsqueda semántica y recuperación de información dentro del sistema RAG.

## Actividades

- Seleccionar el modelo de embeddings que será utilizado en el proyecto.
- Integrar el modelo de embeddings con los documentos previamente segmentados.
- Generar embeddings para los chunks producidos en la etapa de chunking.
- Verificar la dimensionalidad y consistencia de los vectores generados.
- Realizar pruebas con diferentes fragmentos de contenido.
- Documentar el modelo seleccionado y el proceso de generación de embeddings.

## Entregables

- Proceso de generación de embeddings implementado.
- Código utilizado para generar las representaciones vectoriales.
- Evidencia de embeddings generados a partir de los chunks.
- Documentación del modelo de embeddings seleccionado y su justificación.
- Evidencia del trabajo realizado en el repositorio.

## Criterios de aceptación

- Los chunks pueden ser transformados correctamente en embeddings.
- El modelo de embeddings utilizado está identificado y justificado.
- Los vectores generados presentan una estructura y dimensionalidad consistentes.
- La implementación puede ejecutarse de manera reproducible.
- El código y la documentación correspondiente están disponibles en el repositorio.
